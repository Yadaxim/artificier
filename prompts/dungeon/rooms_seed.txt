- Floors below the entrance use negative floor_level values (-1, -2, -3, ...).

- Define the connection topology between rooms on the same floor and between adjacent floors.

Length: "short", "medium", or "long".

Vertical connections MUST be made concrete in the topology:
- If a room has vertical_connection = "up", create at least one connection from that room to a room on floor_level + 1.
- If a room has vertical_connection = "down", create at least one connection from that room to a room on floor_level - 1.
- If a room has vertical_connection = "both", create at least one connection up and at least one connection down.
- Make sure the "connections" list below includes these cross-floor links using from_room_name/to_room_name, and that the target room's floor_level reflects the correct level.
